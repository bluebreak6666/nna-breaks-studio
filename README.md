# NNA BREAKS STUDIO · 好好開卡控制台

為 NNA Breaks 製作的非官方贈禮提案，由 Blue 提供。參考 https://nnabreaks.com/ 的奶油白、可可棕與金色星光，使用原創字樣徽章與 CSS 收藏卡插畫。未複製官網人物商標或商品圖片。

## 使用

GitHub Pages：main 分支 / 根目錄。開啟 index.html 網站，名單、紀錄與刮刮樂結果保存在本機瀏覽器；與原 teambreak 的儲存鍵及直播同步頻道隔離。

- 轉盤：每行加入一位參加者；重複姓名視為多個名額。
- 隨機分隊：NBA、尾號、位置範本；可補足空白或固定值，匯出 CSV / PNG。
- 刮刮樂：每行一份獎項，開局固定分配；支援重複品項、刷新續局、按鈕或擦拭揭曉。
- 骰子與擲筊、音效控制、操作累計與歷史紀錄。
- 直播畫面：同一瀏覽器另開視窗供 OBS 視窗擷取；奶油可可外框與綠幕外框。
- 球卡 OCR 與球員查詢需要連網，辨識後應人工確認。

官網與 YouTube 連結僅作為品牌入口；此工具無購物、金流或會員功能。它是本機操作工具，不是防竄改的第三方抽獎服務。

## 原始碼

下載 nna-studio-source.zip 解壓，執行 npm ci，再 npm run build:pages，輸出 docs/。建置頁面及 assets 可直接部署到 GitHub Pages。根目錄 index.html 為已合併資源的發行版，音效另以相對路徑載入。
